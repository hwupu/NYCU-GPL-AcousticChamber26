# RT60 calibration reports

Sweep reports (`RT60_<chamber>_<yyyyMMdd-HHmmss>.csv` + `.txt`) that calibration tables were imported from, copied here by
`Magic > Acoustics > Import RT60 Calibration...` (GPL.Acoustics, ADR-0010). Each table asset in
`Assets/AcousticChamber/Calibration/Resources/RT60Calibration/` names its report in `sourceReport`. Commit both together.

Measurement reports that verify the targets (kind `measurement`) are kept in `docs/measures/` (added by hand when they are cited).
Protocol and columns: `Assets/AcousticChamber/Modules/Acoustics/README.md` ("RT60 measurement protocol", "Report").
